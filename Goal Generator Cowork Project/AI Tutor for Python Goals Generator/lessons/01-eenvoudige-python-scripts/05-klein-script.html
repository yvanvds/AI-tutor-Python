Je hebt nu alle stukken om een echt klein scriptje te schrijven: vragen wat je nodig hebt met input, opslaan in variabelen, een berekening doen, en het resultaat tonen met print. In deze les zet je die bouwstenen samen.

De vaste vorm

De meeste kleine scripts volgen dezelfde drie stappen, in deze volgorde:

  1. Vraag de invoer op en zet ze om naar het juiste type.
  2. Bereken het antwoord.
  3. Toon het resultaat.

Bijvoorbeeld een script dat het gemiddelde van twee getallen berekent:

a = float(input("Eerste getal? "))
b = float(input("Tweede getal? "))
gemiddelde = (a + b) / 2
print("Het gemiddelde is", gemiddelde)

Typt de gebruiker 7 en 10, dan toont het script Het gemiddelde is 8.5. De volgorde van de regels is belangrijk: een variabele moet bestaan voor je haar gebruikt, dus eerst a en b ophalen, dan pas het gemiddelde berekenen.

Een script lezen en traceren

Je kan een script ook stap voor stap doorlopen op papier — voor elke regel noteer je wat er met de variabelen gebeurt. Neem dit script:

prijs = float(input("Prijs? "))
aantal = int(input("Aantal? "))
totaal = prijs * aantal
print("Totaal:", totaal, "euro")

Stel dat de gebruiker 2.5 en 4 typt. Na regel 1 bevat prijs de waarde 2.5. Na regel 2 bevat aantal de waarde 4. Regel 3 rekent 2.5 * 4 uit en stopt het resultaat 10.0 in totaal. Regel 4 toont Totaal: 10.0 euro.

Veelvoorkomende fouten

Er zijn drie fouten die je in deze fase vaak ziet. Ze hebben allemaal te maken met het samenspel tussen input, conversie, en de berekening.

Vergeten om te zetten. Als je vergeet int of float rond input te zetten, krijg je een string in plaats van een getal. Bij optellen geeft dat ofwel een TypeError (als je probeert tekst en een getal te combineren), ofwel een verkeerd antwoord (als je twee strings optelt: "5" + "3" wordt "53", niet 8).

a = input("Eerste? ")
b = input("Tweede? ")
print(a + b)

Voor inputs 5 en 3 toont dit 53. De fix: zet int(...) rond beide input-aanroepen.

Haakjes vergeten in de berekening. Wiskundige formules vertalen letterlijk lukt niet altijd. "Het gemiddelde van a en b" wordt in Python niet a + b / 2, want dan deelt Python eerst b door 2 en telt a er pas daarna bij op. Je hebt haakjes nodig: (a + b) / 2.

De gebruiker typt iets dat niet kan worden omgezet. Bij int(input(...)) verwacht je een geheel getal. Typt de gebruiker zeven of 3.5, dan crasht het script met een ValueError. Daar is in dit hoofdstuk nog geen oplossing voor — voorlopig vertrouw je erop dat de gebruiker invoer typt die past bij wat je vraagt.

Een handige gewoonte bij het debuggen: voeg tijdelijk een extra print toe na elke variabele-toekenning om te zien wat er werkelijk in zit. Als het resultaat niet klopt, kan je zo precies aanwijzen waar het fout liep — bij het inlezen, bij de conversie, of bij de berekening.

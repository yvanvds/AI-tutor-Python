Met print() toon je iets op het scherm. Wat tussen de haakjes staat verschijnt als uitvoer wanneer je het script uitvoert. De broncode zelf zie je niet — alleen wat print doorgeeft.

Tekst tonen

Tekst zet je tussen aanhalingstekens. Python noemt zo'n stukje tekst een string. Enkele en dubbele aanhalingstekens werken allebei, als je hetzelfde paar gebruikt om te beginnen en te eindigen.

print("Hallo wereld")
print('Tot ziens')

Uitvoer:

Hallo wereld
Tot ziens

Merk op: de aanhalingstekens verschijnen niet in de uitvoer. Ze horen bij de broncode en vertellen Python "dit is tekst".

Getallen tonen

Bij getallen gebruik je geen aanhalingstekens. Een getal is geen tekst.

print(42)
print(3.14)

Uitvoer:

42
3.14

Schrijf je print(hallo) zonder aanhalingstekens, dan denkt Python dat hallo de naam van iets is dat je eerder hebt gemaakt. Bestaat die naam niet, dan krijg je een NameError. Aanhalingstekens zijn dus geen optionele versiering — ze maken het verschil tussen tekst en een naam.

Meerdere waarden tegelijk

Wil je meerdere dingen op één regel tonen, dan kan je ze scheiden met een komma binnen één print-aanroep. Python plaatst dan automatisch een spatie tussen elk stuk.

print("Score:", 5)
print("De som is", 3, "+", 4)

Uitvoer:

Score: 5
De som is 3 + 4

Je ziet dat de komma's in de broncode niet in de uitvoer staan; ze worden vervangen door spaties.

Komma versus plus

Er bestaat ook een manier om tekst met een + aan elkaar te plakken. Belangrijk verschil: + werkt alleen tussen twee strings, en het voegt geen spatie toe.

print("Hallo" + "wereld")
print("Hallo", "wereld")

Uitvoer:

Hallowereld
Hallo wereld

Met + kan je tekst en een getal niet combineren. print("score: " + 5) geeft een TypeError, omdat + tussen een string en een getal niet weet wat het moet doen — optellen of plakken? Wil je tekst en een getal samen tonen, gebruik dan de komma-vorm: print("score:", 5).

Daarmee kan je een eerste eigen scriptje typen en kijken wat er op het scherm verschijnt.

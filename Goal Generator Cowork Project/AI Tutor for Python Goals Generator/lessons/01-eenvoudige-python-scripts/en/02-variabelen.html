A variable is a name you link to a value, so that you can call up that value later simply by using the name. That way you don't have to type the same text or the same number again every time, and you can keep values during a script.

Assigning with =

You link a value to a name with the equals sign. The name goes on the left, the value on the right.

name = "Mira"
age = 16
print(name)
print(age)

Output:

Mira
16

Read = as "becomes". So it is not a mathematical equality, but an instruction with a direction: from right to left.

Using the variable

Once a variable exists, you can use it anywhere you would otherwise type the value itself — in print, or together with other values.

name = "Mira"
print("Hello", name)

Output:

Hello Mira

Watch the difference between name and "name". Without quotation marks, name refers to the value you stored. With quotation marks, it is just the text name.

name = "Mira"
print("name")
print(name)

Output:

name
Mira

Overwriting a value

A variable can get a new value when you assign something to it again. The old value is then gone.

x = 10
x = 20
print(x)

Output:

20

The new value can also depend on the old one. Python then first looks at what is on the right, and only then puts the result into the name on the left.

x = 10
x = x + 1
print(x)

Output:

11

So the line x = x + 1 means: take the current value of x (10), add 1 to it, and store that result as the new x.

Rules for names

Not every piece of text works as a variable name. Python has a few rules:

  • A name starts with a letter or an underscore, not with a digit. score and _score are allowed, 2score is not.
  • A name contains only letters, digits and underscores. No hyphen, no space. my_score is allowed, my-score and my score are not.
  • A name can't be a Python keyword, such as for or if.
  • Capital letters count: name and Name are two different variables.

Text or number

The quotation marks decide the type of the value. "16" is text that happens to consist of digits. 16 without quotation marks is a number you can calculate with.

a = "16"
b = 16

They look the same on the screen when you print them, but Python treats them differently.

In Belgium you write decimal numbers with a comma, but Python expects a point. pi = 3,14 is not a decimal number — Python reads it as two separate values in a row and puts them into pi as a pair. If you want 3,14 as a number, write pi = 3.14.

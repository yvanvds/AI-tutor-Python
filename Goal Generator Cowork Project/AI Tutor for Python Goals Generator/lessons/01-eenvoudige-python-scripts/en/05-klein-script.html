You now have all the pieces to write a real small script: ask for what you need with input, store it in variables, do a calculation, and show the result with print. In this lesson you put those building blocks together.

The fixed shape

Most small scripts follow the same three steps, in this order:

  1. Ask for the input and convert it to the right type.
  2. Calculate the answer.
  3. Show the result.

For example, a script that calculates the average of two numbers:

a = float(input("First number? "))
b = float(input("Second number? "))
average = (a + b) / 2
print("The average is", average)

If the user types 7 and 10, the script shows The average is 8.5. The order of the lines matters: a variable has to exist before you use it, so first get a and b, and only then calculate the average.

Reading and tracing a script

You can also go through a script step by step on paper — for each line, you write down what happens to the variables. Take this script:

price = float(input("Price? "))
quantity = int(input("Quantity? "))
total = price * quantity
print("Total:", total, "euro")

Suppose the user types 2.5 and 4. After line 1, price holds the value 2.5. After line 2, quantity holds the value 4. Line 3 works out 2.5 * 4 and puts the result 10.0 into total. Line 4 shows Total: 10.0 euro.

Common mistakes

There are three mistakes you often see at this stage. They all have to do with how input, conversion and the calculation work together.

Forgetting to convert. If you forget to put int or float around input, you get a string instead of a number. When adding, that gives either a TypeError (if you try to combine text and a number) or a wrong answer (if you add two strings: "5" + "3" becomes "53", not 8).

a = input("First? ")
b = input("Second? ")
print(a + b)

For inputs 5 and 3 this shows 53. The fix: put int(...) around both input calls.

Forgetting parentheses in the calculation. Translating math formulas word for word doesn't always work. "The average of a and b" is not a + b / 2 in Python, because then Python first divides b by 2 and only adds a after that. You need parentheses: (a + b) / 2.

The user types something that can't be converted. With int(input(...)) you expect a whole number. If the user types seven or 3.5, the script crashes with a ValueError. There is no solution for that in this chapter yet — for now, you trust the user to type input that fits what you ask for.

A handy habit when debugging: temporarily add an extra print after each variable assignment to see what is really in it. If the result is wrong, you can point out exactly where it went wrong — when reading the input, in the conversion, or in the calculation.

With input() you ask the user something. The script pauses, waits until the user types something and presses enter, and then gives back what was typed. You usually store that value in a variable to keep working with it.

Asking a question

Between the parentheses of input() you put a piece of text — the prompt. It appears on the screen so the user knows what you want to know. Don't forget to put a space at the end of the prompt, or the input sticks to your question.

name = input("What is your name? ")
print("Hello", name)

Whatever the user types — for example Mira — ends up in name. Then print shows the greeting.

Input always gives a string

This is the most important rule of this lesson: input() always gives back a string, even when the user types a number. For Python, the "42" the user typed is just text that happens to consist of digits — not a number.

age = input("How old are you? ")
print(age + 1)

The script above crashes. The user types 16, but age holds the string "16". And Python can't carry out "16" + 1 — you can't add a string and a number, so you get a TypeError.

An even subtler variant: ask for two numbers without converting them, and add them up.

a = input("First number? ")
b = input("Second number? ")
print(a + b)

If the user types 5 and 3, 53 appears on the screen, not 8. Between two strings, + means gluing, not adding. The script gives no error message, just a wrong answer — that kind of bug is harder to find.

Converting to a number

If you want to calculate with the input, you first convert the string to a number. There are two functions for that: int() for whole numbers and float() for decimal numbers.

age = int(input("How old are you? "))
print("Next year you will be", age + 1)

The inner call input(...) asks for the text, and int(...) immediately converts that text to a whole number. So age holds an int straight away.

For decimal numbers it works the same way:

weight = float(input("What is your weight in kg? "))
print("In grams:", weight * 1000)

When the conversion fails

Not every piece of text can be converted to a number. What the user types really has to look like a valid number, or you get a ValueError and the script stops.

int("16") works. int("sixteen") doesn't, because that is not a number. int("3.5") doesn't work either — int expects a whole number without a comma or point. For 3.5 you need float.

In Belgium you write 3,14 with a comma, but float expects a point. If the user types 3,14 at a float(input(...)) question, the script crashes with a ValueError. If you want the script to work, the user has to type a point.

In a class of 25 students: how big is the probability that two of them have their birthday on the same day? You answer such a question with a simulation, and you build every simulation the same way.

First a plan

Before you write code, you answer four questions.

QuestionFor the birthdays
What is one experiment?A group of 25 people, each with a random birthday
What does the experiment give back?True if two people have the same birthday, otherwise False
What do you count or measure?The share of experiments that gives True
How often do you repeat?10 000 times

The experiment as a function

import random

def has_duplicate(group):
    days = []
    for i in range(group):
        day = random.randint(1, 365)
        if day in days:
            return True
        days.append(day)
    return False

Every person gets a day from 1 up to and including 365. If that day is already in the list, there is a duplicate and the function stops with True. Otherwise the day goes into the list.

You check what an experiment does with random values you choose yourself. Suppose the days drawn are 40, 112, 7 and 112. At the fourth person 112 is already in the list: the function gives back True, and the rest of the group never gets its turn.

Repeating and estimating

def estimate_probability(group, repetitions):
    successes = 0
    for i in range(repetitions):
        if has_duplicate(group):
            successes = successes + 1
    return successes / repetitions

print(estimate_probability(25, 10000))

One possible output:

0.5671

So more than half of the classes have two students with the same birthday. That is much more than most people expect.

Checking with a known case

print(estimate_probability(1, 1000))
print(estimate_probability(366, 1000))

Output:

0.0
1.0

You only trust a surprising result once the simulation is right for cases whose answer you know. One person can't share a birthday: the probability has to be 0. With 366 people and 365 days a duplicate is unavoidable: the probability has to be 1. If your simulation gives something else there, it contains an error.

Repeating until it succeeds

def rolls_until_six():
    count = 0
    roll = 0
    while roll != 6:
        roll = random.randint(1, 6)
        count = count + 1
    return count

def average_rolls(repetitions):
    total = 0
    for i in range(repetitions):
        total = total + rolls_until_six()
    return total / repetitions

print(rolls_until_six())
print(average_rolls(10000))

One possible output:

3
6.0187

An experiment doesn't have to give back True or False. Here the outcome is a number: the number of rolls until the first six. How many rolls that will be is not fixed, so the experiment is a while.

Of such an experiment you don't estimate a probability but an average: you add up the outcomes and divide by the number of repetitions. On average you need about 6 rolls.

Drawing without putting back, such as cards from a deck, you do with card = random.choice(deck) followed by deck.remove(card).

An experiment, a repetition and a check: with those you turn a story with randomness into a number you can trust.

A die, a coin, a card from a deck: with the module random you let Python make such random choices. Every time you run the script, the outcome can be different.

A whole number

import random

roll = random.randint(1, 6)
print(roll)

One possible output:

5

random.randint(1, 6) gives a whole number from 1 up to and including 6. Both limits are included: unlike with range(1, 6), the 6 can come up. You import the module like math and turtle.

A decimal number or a choice from a list

print(random.random())
print(random.choice(["heads", "tails"]))

One possible output:

0.6229016948897019
tails

random.random() gives a decimal number from 0 to 1: 0.0 can occur, 1.0 never. random.choice picks a random element from a list.

What can appear?

a = random.randint(1, 3)
b = random.randint(1, 3)
print(a + b)

What this script shows, you can't predict. What it can show, you can: every whole number from 2 up to and including 6. A 1 or a 7 is impossible. That is how you look at every script with randomness: you don't ask what the output is, but which output is possible.

An event with a given probability

if random.random() < 0.3:
    print("rain")
else:
    print("dry")

One possible output:

dry

In 30 percent of the cases random.random() is below 0.3. So the condition is true with a probability of 30 percent. If you turn the sign around to >, it is true in 70 percent of the cases.

One roll, one variable

if random.randint(1, 6) == 6:
    print("six")
elif random.randint(1, 6) == 5:
    print("five")
else:
    print("something else")

This script rolls twice. Every call of random.randint produces a new number, so the second condition tests a different roll than the first. Store the roll in a variable first, as in the first example, and then test that variable.

A function with randomness

def roll_die():
    return random.randint(1, 6)

def two_dice():
    return roll_die() + roll_die()

print(two_dice())

One possible output:

8

A function that uses random gives back a new value at every call, even when it has no parameters. That is the exception to what you saw with functions: the same call, yet a different result.

roll_die() + roll_die() is two rolls. 2 * roll_die() is one roll that is doubled, so it can never be odd.

With that you can act out every game of chance and every random process in code.

Gooi geblinddoekt duizend pijltjes naar een rechthoekig bord waarop een figuur getekend is. Het deel van de pijltjes dat in de figuur belandt, vertelt je hoe groot de figuur is.

Een toevallig punt

import random

x = random.uniform(0, 4)
y = random.uniform(0, 3)
print(round(x, 2), round(y, 2))

Een mogelijke uitvoer:

2.49 2.23

random.uniform(a, b) geeft een kommagetal tussen a en b. Twee zulke getallen vormen een punt dat overal in de rechthoek van 4 op 3 even gemakkelijk terechtkomt.

Treffer of niet

Voor elke figuur heb je een test nodig die zegt of een punt erin ligt. Een punt ligt binnen de cirkel met middelpunt (0, 0) en straal 1 als x² + y² kleiner is dan 1.

def in_cirkel(x, y):
    return x ** 2 + y ** 2 < 1

print(in_cirkel(0.5, 0.5))
print(in_cirkel(0.9, 0.8))

Uitvoer:

True
False

Voor het punt (0.5, 0.5) is de som 0.5: een treffer. Voor (0.9, 0.8) is ze 1.45: ernaast. Zo ga je voor elk punt na wat de voorwaarde beslist.

Voor het gebied onder de grafiek van een functie f is de test y < f(x): het punt ligt lager dan de grafiek.

Van treffers naar oppervlakte

def schat_pi(herhalingen):
    treffers = 0
    for i in range(herhalingen):
        x = random.uniform(0, 1)
        y = random.uniform(0, 1)
        if in_cirkel(x, y):
            treffers = treffers + 1
    return treffers / herhalingen * 4

print(schat_pi(100000))

Een mogelijke uitvoer:

3.14124

De punten vallen overal in het vierkant van 1 op 1 even dicht. Het aandeel punten binnen de kwartcirkel is daarom het deel van het vierkant dat de kwartcirkel inneemt. Het vierkant heeft oppervlakte 1, dus het aandeel treffers is meteen de oppervlakte van de kwartcirkel. Een hele cirkel met straal 1 heeft oppervlakte pi; maal 4 geeft dus een schatting van pi.

Een andere rechthoek

def f(x):
    return x ** 2

def schat_oppervlakte(herhalingen):
    treffers = 0
    for i in range(herhalingen):
        x = random.uniform(0, 2)
        y = random.uniform(0, 4)
        if y < f(x):
            treffers = treffers + 1
    return treffers / herhalingen * 8

print(schat_oppervlakte(100000))

Een mogelijke uitvoer:

2.6652

Dit schat de oppervlakte onder de parabool tussen x = 0 en x = 2. De rechthoek is 2 breed en 4 hoog en heeft dus oppervlakte 8. Het aandeel treffers maal 8 geeft de oppervlakte onder de grafiek.

Het aandeel treffers is nog geen oppervlakte: vergeet de vermenigvuldiging met de oppervlakte van de rechthoek niet. De rechthoek moet ook de hele figuur omvatten. Hier moet hij 4 hoog zijn, want f(2) = 4; met een lagere rechthoek mis je een stuk.

Zo meet je een oppervlakte waarvoor je geen formule kent, met alleen toeval en een teller.

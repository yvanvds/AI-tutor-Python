Een wandelaar zet elke seconde één stap, naar links of naar rechts, en laat een muntstuk beslissen. Zo'n toevalswandeling is het eenvoudigste model voor alles wat in kleine toevallige stapjes verandert: een stofje in water, het geld van een gokker, een beurskoers.

Een wandeling op een lijn

import random

def wandeling(stappen):
    positie = 0
    for i in range(stappen):
        positie = positie + random.choice([-1, 1])
    return positie

print(wandeling(100))

Een mogelijke uitvoer:

8

De positie begint op 0 en gaat bij elke stap één omhoog of één omlaag. Na 100 stappen kan de wandelaar ten hoogste op 100 of -100 staan, maar meestal staat hij veel dichter bij 0.

Sommige posities zijn onmogelijk. Na een even aantal stappen is de positie altijd even, na een oneven aantal altijd oneven. Na 3 stappen zijn dus alleen -3, -1, 1 en 3 mogelijk.

De weg bewaren

def wandeling_met_weg(stappen):
    positie = 0
    weg = [positie]
    for i in range(stappen):
        positie = positie + random.choice([-1, 1])
        weg.append(positie)
    return weg

print(wandeling_met_weg(10))

Een mogelijke uitvoer:

[0, 1, 2, 1, 2, 1, 0, -1, -2, -1, 0]

De lijst begint met de startpositie en krijgt er na elke stap één element bij: 10 stappen geven 11 posities. Met max(weg) en min(weg) zie je hoe ver de wandeling geraakt is.

Stoppen bij een grens

def speel_tot_einde(geld, doel):
    while 0 < geld and geld < doel:
        geld = geld + random.choice([-1, 1])
    return geld

print(speel_tot_einde(5, 10))

Een mogelijke uitvoer:

0

Een speler begint met 5 euro en wint of verliest elke ronde 1 euro. Hij stopt als hij blut is of zijn doel van 10 euro haalt. Het aantal stappen ligt niet vast, dus dit is een while: de wandeling gaat door zolang het geld tussen de twee grenzen ligt. De functie geeft 0 of 10 terug.

Eén wandeling zegt weinig

def gemiddelde_positie(stappen, herhalingen):
    som = 0
    for i in range(herhalingen):
        som = som + wandeling(stappen)
    return som / herhalingen

def gemiddelde_afstand(stappen, herhalingen):
    som = 0
    for i in range(herhalingen):
        som = som + abs(wandeling(stappen))
    return som / herhalingen

print(gemiddelde_positie(100, 2000))
print(gemiddelde_afstand(100, 2000))
print(gemiddelde_afstand(400, 2000))

Een mogelijke uitvoer:

-0.132
8.01
15.713

abs(x) geeft de absolute waarde van x: de afstand tot 0, zonder teken.

De gemiddelde eindpositie ligt rond 0, want wandelingen die links eindigen en wandelingen die rechts eindigen heffen elkaar op. Bij de afstand heft niets elkaar op: -8 en 8 tellen allebei als 8. De gemiddelde afstand is daarom niet nul, en ze groeit met het aantal stappen. Ze groeit wel trager dan het aantal stappen zelf: vier keer zoveel stappen geeft ongeveer een dubbele afstand.

Eén wandeling kan toevallig ver weg eindigen of net op 0. Pas als je er veel herhaalt, zie je wat een wandeling typisch doet.

Een wandeling tekenen

import turtle

t = turtle.Turtle()
for i in range(200):
    t.left(random.choice([0, 90, 180, 270]))
    t.forward(10)
turtle.done()

In het vlak kiest de turtle bij elke stap een van de vier richtingen en gaat dan 10 vooruit.

Met een positie, een toevallige stap en een lus speel je elk proces na dat stap voor stap door het toeval geduwd wordt.

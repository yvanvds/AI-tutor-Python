In een klas van 25 leerlingen: hoe groot is de kans dat twee van hen op dezelfde dag jarig zijn? Zo'n vraag beantwoord je met een simulatie, en elke simulatie bouw je op dezelfde manier op.

Eerst een plan

Voor je code schrijft, beantwoord je vier vragen.

VraagVoor de verjaardagen
Wat is één experiment?Een groep van 25 mensen, elk met een toevallige verjaardag
Wat geeft het experiment terug?True als twee mensen dezelfde verjaardag hebben, anders False
Wat tel of meet je?Het aandeel experimenten dat True geeft
Hoe vaak herhaal je?10 000 keer

Het experiment als functie

import random

def heeft_dubbele(groep):
    dagen = []
    for i in range(groep):
        dag = random.randint(1, 365)
        if dag in dagen:
            return True
        dagen.append(dag)
    return False

Elke persoon krijgt een dag van 1 tot en met 365. Zit die dag al in de lijst, dan is er een dubbele en stopt de functie met True. Anders komt de dag in de lijst.

Wat een experiment doet, ga je na met toevalswaarden die je zelf kiest. Stel dat de getrokken dagen 40, 112, 7 en 112 zijn. Bij de vierde persoon zit 112 al in de lijst: de functie geeft True terug, en de rest van de groep komt niet meer aan bod.

Herhalen en schatten

def schat_kans(groep, herhalingen):
    successen = 0
    for i in range(herhalingen):
        if heeft_dubbele(groep):
            successen = successen + 1
    return successen / herhalingen

print(schat_kans(25, 10000))

Een mogelijke uitvoer:

0.5671

Meer dan de helft van de klassen heeft dus twee leerlingen met dezelfde verjaardag. Dat is veel meer dan de meeste mensen verwachten.

Controleren met een bekend geval

print(schat_kans(1, 1000))
print(schat_kans(366, 1000))

Uitvoer:

0.0
1.0

Een verrassend resultaat vertrouw je pas als de simulatie klopt voor gevallen waarvan je het antwoord kent. Eén persoon kan geen verjaardag delen: de kans moet 0 zijn. Met 366 mensen en 365 dagen is een dubbele onvermijdelijk: de kans moet 1 zijn. Geeft je simulatie daar iets anders, dan zit er een fout in.

Herhalen tot het lukt

def worpen_tot_zes():
    aantal = 0
    worp = 0
    while worp != 6:
        worp = random.randint(1, 6)
        aantal = aantal + 1
    return aantal

def gemiddeld_aantal_worpen(herhalingen):
    som = 0
    for i in range(herhalingen):
        som = som + worpen_tot_zes()
    return som / herhalingen

print(worpen_tot_zes())
print(gemiddeld_aantal_worpen(10000))

Een mogelijke uitvoer:

3
6.0187

Een experiment hoeft geen True of False terug te geven. Hier is de uitkomst een getal: het aantal worpen tot de eerste zes. Hoeveel worpen dat worden, ligt niet vast, dus het experiment is een while.

Van zo'n experiment schat je geen kans maar een gemiddelde: je telt de uitkomsten op en deelt door het aantal herhalingen. Gemiddeld heb je ongeveer 6 worpen nodig.

Trekken zonder terugleggen, zoals kaarten uit een stapel, doe je met kaart = random.choice(stapel) gevolgd door stapel.remove(kaart).

Een experiment, een herhaling en een controle: daarmee maak je van een verhaal met toeval een getal dat je kan vertrouwen.

Een dobbelsteen, een muntstuk, een kaart uit een stapel: met de module random laat je Python zulke toevallige keuzes maken. Elke keer dat je het script uitvoert, kan de uitkomst anders zijn.

Een geheel getal

import random

worp = random.randint(1, 6)
print(worp)

Een mogelijke uitvoer:

5

random.randint(1, 6) geeft een geheel getal van 1 tot en met 6. Beide grenzen doen mee: anders dan bij range(1, 6) kan de 6 dus vallen. De module importeer je zoals math en turtle.

Een kommagetal of een keuze uit een lijst

print(random.random())
print(random.choice(["kop", "munt"]))

Een mogelijke uitvoer:

0.6229016948897019
munt

random.random() geeft een kommagetal van 0 tot 1: 0.0 kan voorkomen, 1.0 nooit. random.choice kiest een willekeurig element uit een lijst.

Wat kan er verschijnen?

a = random.randint(1, 3)
b = random.randint(1, 3)
print(a + b)

Wat dit script toont, kan je niet voorspellen. Wat het kan tonen wel: elk geheel getal van 2 tot en met 6. Een 1 of een 7 is onmogelijk. Zo kijk je naar elk script met toeval: je vraagt niet wat de uitvoer is, maar welke uitvoer mogelijk is.

Een gebeurtenis met een gegeven kans

if random.random() < 0.3:
    print("regen")
else:
    print("droog")

Een mogelijke uitvoer:

droog

In 30 procent van de gevallen ligt random.random() onder 0.3. De voorwaarde is dus waar met een kans van 30 procent. Draai je het teken om naar >, dan is ze waar in 70 procent van de gevallen.

Eén worp, één variabele

if random.randint(1, 6) == 6:
    print("zes")
elif random.randint(1, 6) == 5:
    print("vijf")
else:
    print("iets anders")

Dit script gooit twee keer. Elke aanroep van random.randint levert een nieuw getal, dus de tweede voorwaarde test een andere worp dan de eerste. Bewaar de worp eerst in een variabele, zoals in het eerste voorbeeld, en test daarna die variabele.

Een functie met toeval

def gooi():
    return random.randint(1, 6)

def twee_dobbelstenen():
    return gooi() + gooi()

print(twee_dobbelstenen())

Een mogelijke uitvoer:

8

Een functie die random gebruikt, geeft bij elke aanroep een nieuwe waarde terug, ook als ze geen parameters heeft. Dat is de uitzondering op wat je bij functies zag: dezelfde aanroep, toch een ander resultaat.

gooi() + gooi() zijn twee worpen. 2 * gooi() is één worp die verdubbeld wordt, en kan dus nooit oneven zijn.

Daarmee kan je elk kansspel en elk toevallig proces in code naspelen.

A for loop can run not only over range, but also directly over a list or a string. That way you process every element, one by one.

Looping over the elements

names = ["Aya", "Bram", "Chloë"]
for name in names:
    print("Hello", name)

Output:

Hello Aya
Hello Bram
Hello Chloë

The loop variable name gets the next element on every iteration. Give it a name that says what is in it: name for a list of names, number for a list of numbers.

A string works just the same; the loop then gives you one character at a time:

for letter in "cat":
    print(letter)

Output:

c
a
t

Looping over the indexes

range(len(my_list)) gives exactly the valid indexes of a list: from 0 up to and including the length minus one. With that index you get the element itself.

scores = [12, 7, 15]
for i in range(len(scores)):
    print(i, scores[i])

Output:

0 12
1 7
2 15

You need the index if you want to change elements:

for i in range(len(scores)):
    scores[i] = scores[i] * 2
print(scores)

Output:

[24, 14, 30]

You also need the index if you want to compare an element with its neighbor. Here the loop stops one place earlier, otherwise i + 1 would fall outside the list:

temperatures = [14, 18, 11, 17]
for i in range(len(temperatures) - 1):
    print(temperatures[i + 1] - temperatures[i])

Output:

4
-7
6

In for x in scores:, x gets a copy of the value. x = x * 2 then only changes x, not the list. If you want to change the list itself, use the index: scores[i] = scores[i] * 2.

Which loop do you choose?

If you only need the values, loop over the elements. That loop is shorter and reads like plain language: "for each name in names". If you need the position, because you want to change something or compare with a neighbor, loop over the indexes.

Don't mix the two up. In for i in scores:, i is already a value such as 12, not a position. scores[i] then looks for the element at position 12.

Building a new list

Often you want to keep the original list and make a new one. You start with an empty list before the loop and, in the loop, add what you want to keep.

numbers = [4, 11, 7, 20, 3]
big = []
doubled = []
for number in numbers:
    if number > 5:
        big.append(number)
    doubled.append(number * 2)
print(big)
print(doubled)

Output:

[11, 7, 20]
[8, 22, 14, 40, 6]

big filters: only what meets the condition goes in. doubled transforms: every element goes in, but changed. Always put the empty list before the loop; inside the loop it would start empty again on every iteration.

Drawing from a list

With turtle, a list can decide how long each side gets and which color it gets. Because you need two lists at the same position, you loop over the indexes.

import turtle

t = turtle.Turtle()
lengths = [50, 100, 150, 200]
colors = ["red", "orange", "green", "blue"]
for i in range(len(lengths)):
    t.pencolor(colors[i])
    t.forward(lengths[i])
    t.left(90)
turtle.done()

That draws an angular spiral in which each side is longer than the previous one, each time in a different color. If you want a different shape, you only change the lists.

With that, you can loop through any list or string, change it, or turn it into a new list.

A list is not fixed. While your program runs, you can add elements to it, slide them in between, take them out and change the order.

Methods of a list

A list has its own instructions, methods. You call them with a dot after the name of the list, just as you wrote t.forward(100) with turtle. A method works directly on the list itself.

Adding: append and insert

append puts a value at the end. insert puts a value at a position you choose; everything after it moves up one place.

groceries = ["bread", "cheese"]
groceries.append("apples")
groceries.insert(0, "milk")
print(groceries)

Output:

['milk', 'bread', 'cheese', 'apples']

With append in a loop you build up a list, starting from an empty list []:

squares = []
for i in range(1, 5):
    squares.append(i * i)
print(squares)

Output:

[1, 4, 9, 16]

Removing: remove and pop

remove looks for a value and takes away the first one it finds. pop takes away the element at a position and gives it back, so you can still use it. Without a number, pop() takes the last element.

numbers = [5, 2, 8, 2]
numbers.remove(2)
print(numbers)
last = numbers.pop()
print(last, numbers)
numbers.pop(0)
print(numbers)

Output:

[5, 8, 2]
2 [5, 8]
[8]

With [3, 0, 1], remove(0) gives the list [3, 1]: the value 0 disappears. pop(0) gives [0, 1]: the element at position 0 disappears. The same number, a different result.

Is it in there? in

With in you ask whether a value occurs in a list. The result is True or False, so you can use it directly in an if.

print("cheese" in groceries)
print("fish" in groceries)

Output:

True
False

That is useful before a remove. If you ask to remove a value that isn't in the list, your program stops with a ValueError. With if "fish" in groceries: in front of it, you avoid that.

Summarizing: sum, min and max

sum adds up all the numbers, min and max give the smallest and the largest. Together with len you immediately have an average.

temperatures = [14, 18, 11, 17]
print(sum(temperatures), min(temperatures), max(temperatures))
average = sum(temperatures) / len(temperatures)
print(average)

Output:

60 11 18
15.0

Notice: these are ordinary functions with the list between parentheses, not methods with a dot.

Sorting with sort

temperatures.sort()
print(temperatures)

Output:

[11, 14, 17, 18]

sort sorts the list itself and gives nothing back. So don't write temperatures = temperatures.sort(): then temperatures holds None afterwards, Python's way of saying "nothing". The same goes for append, insert and remove.

With these methods you let a list grow, shrink and get sorted while your program runs.

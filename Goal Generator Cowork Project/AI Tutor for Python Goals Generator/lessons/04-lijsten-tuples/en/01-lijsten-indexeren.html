A list stores several values under one name, neatly in a row. That way you don't have to make a separate variable for every score, every name or every measurement.

Making a list

You put the values between square brackets, separated by commas. A list can contain numbers, text, or both.

scores = [12, 7, 15, 9]
names = ["Aya", "Bram", "Chloë"]
print(scores)
print(names)

Output:

[12, 7, 15, 9]
['Aya', 'Bram', 'Chloë']

Python shows text in a list with single quotation marks. That is just how it writes it; the values are the same.

Getting elements with an index

Every element has a position number: the index. Python starts counting at 0, so the first element has index 0.

print(scores[0])
print(scores[2])
print(scores[-1])
print(scores[-2])

Output:

12
15
9
15

A negative index counts from the back: -1 is the last element, -2 the one before last. That is handy when you need the end of a list without knowing how long it is.

How long is a list?

With len() you ask for the number of elements. len(scores) gives 4. The valid indexes then go from 0 up to and including 3: the last index is always one less than the length.

print(len(scores))
print(scores[4])

Output:

4
IndexError: list index out of range

A list with 4 elements has no index 4. So scores[len(scores)] always gives an error; the last element is scores[len(scores) - 1], or shorter, scores[-1].

Replacing an element

On the left of = you can also put a position in a list. Then only that element gets a new value; the rest stays as it is.

scores[1] = 10
print(scores)

Output:

[12, 10, 15, 9]

A part of a list: slicing

With two numbers and a colon you take a part out of a list. The start index is included, the end index just isn't, just like with range(1, 4).

days = ["Mon", "Tue", "Wed", "Thu", "Fri"]
print(days[1:4])
print(days[:2])
print(days[3:])

Output:

['Tue', 'Wed', 'Thu']
['Mon', 'Tue']
['Thu', 'Fri']

So days[1:4] contains 4 − 1 = 3 elements. If you leave out the start, the slice starts at the front; if you leave out the end, it runs to the end. A slice is a new list: days itself doesn't change.

A string is a sequence too

Text works the same way: every character has an index, and spaces count too. Indexes, negative indexes, len() and slices all work.

word = "python"
print(word[0])
print(word[-1])
print(word[1:4])
print(len(word))

Output:

p
n
yth
6

With indexes and slices you can now point out exactly any element or any part of a list or text.

Sommige taken met lijsten komen zo vaak terug dat ze een vast patroon hebben: het grootste zoeken, tellen, zoeken, wisselen. Kan je die patronen zelf schrijven, dan kan je ze aanpassen aan elke vraag, ook als er geen kant-en-klare functie voor bestaat.

Het grootste element zoeken

Je houdt een variabele bij met het grootste getal tot nu toe. Je begint met het eerste element en vergelijkt daarna elk element ermee. Is het nieuwe groter, dan neemt het de plaats in.

getallen = [4, 11, 7, 20, 3]
grootste = getallen[0]
for getal in getallen:
    if getal > grootste:
        grootste = getal
print(grootste)

Uitvoer:

20

Voor het kleinste element draai je enkel de vergelijking om: < in plaats van >. max() en min() doen hetzelfde in één regel, maar met het patroon kan je meer: bijvoorbeeld ook onthouden op welke positie het grootste stond.

Begin niet met grootste = 0. Bij [-4, -11, -2] is geen enkel getal groter dan 0, dus het resultaat blijft 0, een getal dat niet eens in de lijst staat. Het eerste element is altijd een veilige start.

Tellen

Tellen is een som waarbij je telkens 1 optelt, maar enkel als een element aan de voorwaarde voldoet.

aantal_even = 0
for getal in getallen:
    if getal % 2 == 0:
        aantal_even = aantal_even + 1
print(aantal_even)

Uitvoer:

2

Zoeken

Met in weet je of een waarde in de lijst staat. Wil je ook weten waar, of zoek je een element dat aan een voorwaarde voldoet, dan loop je over de indexen en onthoud je wat je vond. Een variabele gevonden met True of False houdt bij of het al gelukt is.

namen = ["Aya", "Bram", "Chloë", "Dries"]
zoek = "Chloë"
gevonden = False
positie = -1
for i in range(len(namen)):
    if namen[i] == zoek:
        gevonden = True
        positie = i
if gevonden:
    print("Gevonden op positie", positie)
else:
    print("Niet gevonden")

Uitvoer:

Gevonden op positie 2

Het besluit hoort ná de lus. Zet je print("Niet gevonden") in de lus, in een else bij de vergelijking, dan verschijnt het bij elk element dat niet overeenkomt, ook als de naam verderop wél staat.

Twee elementen wisselen

Om de inhoud van twee glazen te wisselen, heb je een derde glas nodig. Bij een lijst is dat een hulpvariabele.

kleuren = ["rood", "groen", "blauw"]
hulp = kleuren[0]
kleuren[0] = kleuren[2]
kleuren[2] = hulp
print(kleuren)

Uitvoer:

['blauw', 'groen', 'rood']

Zonder hulpvariabele loopt het mis:

kleuren = ["rood", "groen", "blauw"]
kleuren[0] = kleuren[2]
kleuren[2] = kleuren[0]
print(kleuren)

Uitvoer:

['blauw', 'groen', 'blauw']

De eerste regel overschrijft "rood" al. Als de tweede regel de oude waarde wil terugzetten, is die er niet meer.

Met deze vier patronen los je al een groot deel van de vragen op die je over een lijst kan stellen.

Een lijst bewaart meerdere waarden onder één naam, netjes op een rij. Zo hoef je geen aparte variabele te maken voor elke score, elke naam of elke meting.

Een lijst maken

Je zet de waarden tussen vierkante haken, gescheiden door komma's. Een lijst kan getallen bevatten, tekst, of allebei.

punten = [12, 7, 15, 9]
namen = ["Aya", "Bram", "Chloë"]
print(punten)
print(namen)

Uitvoer:

[12, 7, 15, 9]
['Aya', 'Bram', 'Chloë']

Python toont tekst in een lijst met enkele aanhalingstekens. Dat is gewoon zijn schrijfwijze; de waarden zijn dezelfde.

Een negatieve index telt van achteren: -1 is het laatste element, -2 het voorlaatste. Dat is handig als je het einde van een lijst nodig hebt zonder te weten hoe lang ze is.

Hoe lang is een lijst?

Met len() vraag je het aantal elementen op. len(punten) geeft 4. De geldige indexen gaan dan van 0 tot en met 3: de laatste index is altijd één minder dan de lengte.

print(len(punten))
print(punten[4])

Uitvoer:

4
IndexError: list index out of range

Een lijst met 4 elementen heeft geen index 4. punten[len(punten)] geeft dus altijd een fout; het laatste element is punten[len(punten) - 1], of korter punten[-1].

Een element vervangen

Links van = kan je ook een plaats in een lijst zetten. Dan krijgt enkel dat element een nieuwe waarde; de rest blijft staan.

punten[1] = 10
print(punten)

Uitvoer:

[12, 10, 15, 9]

Een stuk uit een lijst: slicing

Met twee getallen en een dubbelpunt haal je een stuk uit een lijst. De beginindex hoort erbij, de eindindex net niet, net zoals bij range(1, 4).

dagen = ["ma", "di", "wo", "do", "vr"]
print(dagen[1:4])
print(dagen[:2])
print(dagen[3:])

Uitvoer:

['di', 'wo', 'do']
['ma', 'di']
['do', 'vr']

dagen[1:4] bevat dus 4 − 1 = 3 elementen. Laat je het begin weg, dan start de slice vooraan; laat je het einde weg, dan loopt ze tot het einde. Een slice is een nieuwe lijst: dagen zelf verandert niet.

Een string is ook een reeks

Tekst werkt op dezelfde manier: elk teken heeft een index, en ook spaties tellen mee. Indexen, negatieve indexen, len() en slices werken allemaal.

woord = "python"
print(woord[0])
print(woord[-1])
print(woord[1:4])
print(len(woord))

Uitvoer:

p
n
yth
6

Met indexen en slices kan je nu elk element of elk stuk van een lijst of tekst precies aanwijzen.

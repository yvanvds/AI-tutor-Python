De lijsten met x-waarden en functiewaarden bouwde je tot nu toe zelf op met een lus. De module numpy doet hetzelfde in één regel, en zo wordt een grafiek in de praktijk bijna altijd gemaakt.

linspace: je eigen x_waarden

import numpy as np

x = np.linspace(0, 2, 5)
print(x)
print(len(x))

Uitvoer:

[0.  0.5 1.  1.5 2. ]
5

np.linspace(start, einde, aantal) doet wat je eigen functie x_waarden deed: het geeft een aantal gelijk verdeelde waarden, met het begin en het einde erbij. Het derde argument is het aantal punten, niet de stap. Vijf punten tussen 0 en 2 liggen vier stappen van 0.5 uit elkaar.

Het resultaat is geen lijst maar een array. Je herkent hem aan de uitvoer: zonder komma's tussen de waarden. Een array heeft een lengte en indexen zoals een lijst, maar hij rekent anders.

Rekenen met een hele array

y = x ** 2 - 4 * x + 3
print(y)

Uitvoer:

[ 3.    1.25  0.   -0.75 -1.  ]

Een bewerking op een array wordt op elk element uitgevoerd. Deze ene regel doet wat je lus deed: voor elke x de functiewaarde berekenen en het resultaat bewaren. y is opnieuw een array, even lang als x.

Een functie die alleen rekent, zoals def f(x): return x ** 2 - 4 * x + 3, werkt daardoor ook als je haar aanroept met een array: f(x) geeft dan alle functiewaarden tegelijk terug.

Een array is geen lijst

lijst = [1, 2, 3]
reeks = np.array([1, 2, 3])
print(lijst * 2)
print(reeks * 2)
print(lijst + [10, 20, 30])
print(reeks + np.array([10, 20, 30]))

Uitvoer:

[1, 2, 3, 1, 2, 3]
[2 4 6]
[1, 2, 3, 10, 20, 30]
[11 22 33]

Met np.array maak je van een lijst een array. Bij een lijst herhaalt * 2 de lijst en plakt + twee lijsten aan elkaar. Bij een array wordt er gerekend: elk element maal 2, en twee arrays van dezelfde lengte element per element opgeteld.

Kijk dus altijd of je een lijst of een array hebt voor je voorspelt wat * of + doet. lijst ** 2 geeft zelfs een TypeError: met een lijst kan je niet rekenen.

Wiskundige functies

import math

print(math.sqrt(x))

Uitvoer:

TypeError: only length-1 arrays can be converted to Python scalars

De functies uit math werken op één getal en kunnen niets met een array. Numpy heeft zijn eigen versies, die op elk element werken: np.sqrt, np.sin en np.cos, en ook de constante np.pi.

print(np.sqrt(np.array([4, 9, 16])))

Uitvoer:

[2. 3. 4.]

Een grafiek in enkele regels

import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 200)
y = np.sin(x)
plt.plot(x, y)
plt.xlabel("x (radialen)")
plt.ylabel("sin(x)")
plt.show()

plt.plot aanvaardt arrays net zo goed als lijsten. Tweehonderd punten tussen 0 en 2π, de sinus van elk punt, en de grafiek toont één volledige golf. De lus en de twee lege lijsten heb je niet meer nodig, maar wat er gebeurt is hetzelfde gebleven: veel punten berekenen en ze met rechte stukjes verbinden.

Met np.linspace en een formule op de hele array teken je een functie zodra je haar voorschrift kent.

De grafiek van een functie is een waardetabel die je tekent. De x-waarden komen in de ene lijst, de functiewaarden in de andere, en plt.plot doet de rest.

Twee lijsten opbouwen

import matplotlib.pyplot as plt

def f(x):
    return x ** 2 - 4 * x + 3

xs = []
ys = []
for i in range(5):
    x = i
    xs.append(x)
    ys.append(f(x))
print(xs)
print(ys)

Uitvoer:

[0, 1, 2, 3, 4]
[3, 0, -1, 0, 3]

In elke doorloop komt er één x in de lijst xs en de bijbehorende functiewaarde in ys. Zo blijven de twee lijsten even lang en horen de waarden per positie bij elkaar.

plt.plot(xs, ys)
plt.title("f(x) = x² - 4x + 3")
plt.xlabel("x")
plt.ylabel("f(x)")
plt.show()

Je herkent een parabool, maar een hoekige: vier rechte stukken tussen vijf punten.

Waarom hoekig?

Matplotlib kent alleen de punten die jij berekent en trekt daartussen rechte lijnstukken. Een kromme tekent het nooit. Met veel punten zijn de stukjes zo kort dat je de hoeken niet meer ziet en de grafiek vloeiend lijkt. Wat tussen twee punten gebeurt, zie je niet: een top of een nulpunt daar slaat de grafiek gewoon over, net zoals een waardetabel met een te grote stap.

Een functie voor de x-waarden

def x_waarden(start, einde, aantal):
    stap = (einde - start) / (aantal - 1)
    waarden = []
    for i in range(aantal):
        waarden.append(start + i * stap)
    return waarden

print(x_waarden(0, 4, 5))
print(len(x_waarden(0, 4, 201)))

Uitvoer:

[0.0, 1.0, 2.0, 3.0, 4.0]
201

Deze functie verdeelt een interval in gelijke stappen en geeft de x-waarden terug, met het begin en het einde erbij. Vijf punten liggen vier stappen uit elkaar. Daarom deel je door aantal - 1 en niet door aantal: er is altijd één punt meer dan er stappen zijn.

xs = x_waarden(0, 4, 201)
ys = []
for x in xs:
    ys.append(f(x))
plt.plot(xs, ys)
plt.show()

Met 201 punten ziet dezelfde parabool er vloeiend uit.

Twee functies vergelijken

def kosten(aantal):
    return 400 + 2 * aantal

def opbrengst(aantal):
    return 6 * aantal

aantallen = x_waarden(0, 200, 51)
k = []
o = []
for a in aantallen:
    k.append(kosten(a))
    o.append(opbrengst(a))
plt.plot(aantallen, k, label="kosten")
plt.plot(aantallen, o, label="opbrengst")
plt.xlabel("aantal verkochte stuks")
plt.ylabel("bedrag (euro)")
plt.legend()
plt.show()

Een bedrijfje heeft 400 euro vaste kosten en 2 euro kosten per stuk, en verkoopt elk stuk voor 6 euro. Teken je beide functies in één figuur, dan zie je waar ze elkaar snijden: bij 100 stuks zijn kosten en opbrengst gelijk. Links daarvan ligt de kostenlijn hoger en maakt het bedrijfje verlies, rechts ervan winst.

Gebruik voor beide lijnen dezelfde lijst x-waarden. Dan staan de twee grafieken boven dezelfde punten en kan je ze eerlijk vergelijken.

Met een lus, twee lijsten en genoeg punten teken je elke functie waarvan je het voorschrift kent.

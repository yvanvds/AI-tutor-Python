Met Python kan je rekenen zoals met een rekenmachine, maar je typt de bewerkingen uit als expressies. Een expressie is een stukje code dat een waarde oplevert — die waarde kan je tonen met print of bewaren in een variabele.

De zeven operatoren

Python heeft zeven standaard rekenoperatoren:

OperatorBetekenisVoorbeeld
+optellen5 + 3 → 8
-aftrekken5 - 3 → 2
*vermenigvuldigen5 * 3 → 15
/delen10 / 4 → 2.5
//gehele deling10 // 4 → 2
%rest bij deling (modulo)10 % 4 → 2
**machtsverheffing2 ** 3 → 8

Je kan ze gewoon in een print stoppen en Python rekent het uit:

print(5 + 3)
print(2 ** 10)

Uitvoer:

8
1024

Voor machtsverheffing gebruik je **, niet ^. Het dakje ^ bestaat wel in Python, maar betekent iets anders dan in de wiskunde. 2 ** 3 is acht, 2 ^ 3 is een heel ander getal.

Delen, gehele deling en rest

Drie operatoren hebben met delen te maken. Het verschil zit in wat je terugkrijgt.

print(10 / 4)
print(10 // 4)
print(10 % 4)

Uitvoer:

2.5
2
2

De gewone deling / geeft het exacte antwoord, eventueel met decimalen. De gehele deling // gooit het stuk na de komma weg en houdt alleen het hele deel over. De modulo % geeft de rest die overblijft na de gehele deling — 10 gedeeld door 4 is 2 keer, met 2 over.

Volgorde van bewerkingen

Python volgt dezelfde regels als de wiskunde: machtsverheffing eerst, dan vermenigvuldigen en delen, dan optellen en aftrekken. Wat aan de linkerkant staat komt eerst aan de beurt als operatoren even sterk zijn.

print(2 + 3 * 4)
print((2 + 3) * 4)

Uitvoer:

14
20

In de eerste regel wordt 3 * 4 eerst berekend (12), pas daarna komt de + 2 erbij. Wil je dat het optellen eerst gebeurt, dan zet je haakjes rond dat stuk.

Hele getallen en kommagetallen

Python kent twee soorten getallen: int (een heel getal, zoals 7) en float (een kommagetal, zoals 2.5). Het verschil hoort bij de waarde, niet bij de operator. Reken je met twee ints en is het resultaat een heel getal, dan blijft het een int. Komt er ergens een float bij kijken, dan wordt het resultaat een float.

print(3 + 4)
print(3 + 4.0)

Uitvoer:

7
7.0

Eén operator is een uitzondering: de gewone deling / geeft altijd een float, ook als het netjes opgaat. Dus 8 / 2 levert 4.0, niet 4. Wil je een int terug bij een nette deling, dan gebruik je //: 8 // 2 geeft 4.

Onthoud ook de regel uit de vorige les: kommagetallen schrijf je met een punt, niet met een komma. 3.14 is een float, 3,14 is iets anders.

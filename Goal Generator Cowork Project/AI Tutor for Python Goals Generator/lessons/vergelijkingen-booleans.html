Een programma moet vaak iets nagaan: is een getal groter dan nul? Zijn twee waarden gelijk? Zulke vragen stel je in Python met een vergelijking, en het antwoord is altijd True (waar) of False (onwaar).

De vergelijkingsoperatoren

Python kent zes operatoren om waarden te vergelijken:

OperatorBetekenis
==is gelijk aan
!=is niet gelijk aan
<is kleiner dan
>is groter dan
<=is kleiner dan of gelijk aan
>=is groter dan of gelijk aan

Een vergelijking is een expressie, net zoals 2 + 3. Python rekent ze uit tot een waarde — alleen is die waarde geen getal, maar True of False.

print(5 > 3)
print(5 == 3)
print(5 != 3)

Uitvoer:

True
False
True

Let op de hoofdletters: Python kent alleen True en False. Schrijf je true of false, dan denkt Python dat je een variabele met die naam bedoelt.

Het antwoord bewaren

Omdat een vergelijking gewoon een waarde oplevert, kan je dat antwoord in een variabele stoppen. Python rekent eerst de rechterkant uit, en bewaart daarna het resultaat.

leeftijd = 17
mag_stemmen = leeftijd >= 18
print(mag_stemmen)

Uitvoer:

False

De variabele mag_stemmen bevat nu de waarde False — niet de vergelijking zelf.

Van zin naar vergelijking

In een opgave staat een voorwaarde meestal in woorden. Vertalen naar Python is dan de juiste operator kiezen: "minstens" wordt >=, "hoogstens" wordt <=, "verschilt van" wordt !=. De zin "de temperatuur is minstens 20 graden" wordt zo:

temperatuur = 23
print(temperatuur >= 20)

Uitvoer:

True

Kijk goed naar het grensgeval: bij "minstens 20" hoort 20 er zelf bij (>=), bij "meer dan 20" niet (>). Precies op de grens maakt dat het verschil tussen True en False.

= of ==

Eén isteken en twee istekens doen iets helemaal anders. x = 5 is een opdracht: stop de waarde 5 in x. x == 5 is een vraag: is x gelijk aan 5? De opdracht bewaart iets, de vraag levert True of False op.

x = 5
print(x == 5)
print(x == 6)

Uitvoer:

True
False

Een string en een getal zijn nooit gelijk, ook al zien ze er hetzelfde uit: "5" == 5 geeft False. Denk aan input() — die geeft altijd een string terug. Wil je invoer vergelijken met een getal, zet ze dan eerst om met int() of float().

Daarmee kan je elke voorwaarde in woorden omzetten naar een vergelijking, en voorspellen of Python er True of False op antwoordt.

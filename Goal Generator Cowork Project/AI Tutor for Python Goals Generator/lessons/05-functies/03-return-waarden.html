Met return gebeuren twee dingen tegelijk: de functie geeft een waarde terug, en ze stopt. Beide bepalen hoe bruikbaar je functies zijn in een groter programma.

Afdrukken is niet teruggeven

Je komt geregeld functies tegen die hun resultaat afdrukken in plaats van het terug te geven:

def toon_dubbel(x):
    print(2 * x)

resultaat = toon_dubbel(4)
print(resultaat)

Uitvoer:

8
None

De 8 komt van de print in de functie. Maar de functie geeft niets terug, en dan levert de aanroep de speciale waarde None op: niets. In resultaat zit dus geen 8. Een berekening zoals toon_dubbel(4) + 1 geeft zelfs een fout, want met None kan je niet rekenen.

Je herstelt dat door de functie te laten teruggeven. Wie haar aanroept, beslist dan wat er met de waarde gebeurt.

def dubbel(x):
    return 2 * x

resultaat = dubbel(4)
print(resultaat)
print(dubbel(4) + 1)

Uitvoer:

8
9

Een teruggegeven waarde kan je opslaan, vergelijken, optellen of doorgeven aan een andere functie. Een afgedrukte waarde staat op het scherm en is voor je programma verloren.

Een functie berekent en geeft terug; het hoofdscript drukt af. Zo blijft elke functie bruikbaar op plaatsen waar je niets op het scherm wil.

Return stopt de functie

Zodra Python een return uitvoert, is de functie klaar. Regels die erna komen, worden overgeslagen. Daardoor kan elke tak van een if zijn eigen resultaat teruggeven:

def absolute_waarde(getal):
    if getal < 0:
        return -getal
    return getal

print(absolute_waarde(-7))
print(absolute_waarde(3))

Uitvoer:

7
3

Bij -7 is de voorwaarde waar: de functie geeft 7 terug en stopt, zodat de laatste regel niet meer aan de beurt komt. Een else is hier niet nodig.

Functies die True of False teruggeven

def is_even(getal):
    return getal % 2 == 0

if is_even(10):
    print("even")

Uitvoer:

even

Een vergelijking levert True of False op, en die waarde geef je meteen terug. Zo'n functie gebruik je rechtstreeks als voorwaarde in een if of while; er == True achter schrijven is overbodig.

Ook midden in een lus beëindigt return de hele functie, niet alleen de lus:

def bevat_negatief(getallen):
    for getal in getallen:
        if getal < 0:
            return True
    return False

print(bevat_negatief([4, -2, 7]))
print(bevat_negatief([4, 2, 7]))

Uitvoer:

True
False

Bij het eerste negatieve getal geeft de functie True terug en stopt ze; de rest van de lijst hoeft niet meer bekeken te worden. Alleen als de lus helemaal doorlopen is zonder iets te vinden, komt Python bij return False.

return False staat na de lus, niet in een else binnen de lus. Met else: return False zou de functie al bij het eerste getal stoppen, nog voor ze de rest bekeken heeft.

Functies die iets doen

Niet elke functie berekent iets. Een functie die met turtle tekent, doet iets: ze heeft geen resultaat en dus geen return. Haar aanroep staat alleen op een regel.

import turtle

t = turtle.Turtle()

def veelhoek(aantal, lengte):
    for i in range(aantal):
        t.forward(lengte)
        t.left(360 / aantal)

veelhoek(3, 100)
veelhoek(6, 50)
turtle.done()

De turtle t maak je één keer aan, bovenaan het script, en de functie gebruikt hem. Met de parameters kies je bij elke aanroep een andere veelhoek.

Wie het verschil tussen teruggeven en afdrukken kent, schrijft functies waar de rest van het programma mee verder kan.

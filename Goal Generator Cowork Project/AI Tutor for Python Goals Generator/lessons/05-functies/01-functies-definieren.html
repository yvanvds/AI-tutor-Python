Uit de wiskunde ken je functies zoals f(x) = 2x: je stopt er een getal in en er komt een getal uit. In Python schrijf je zulke functies zelf, met een naam die zegt wat ze doen.

Van f(x) naar def

def dubbel(x):
    return 2 * x

De eerste regel begint met def. Daarna komt de naam van de functie, tussen haakjes de parameter, en een dubbelepunt. De parameter x is de naam voor de waarde die binnenkomt.

Het ingesprongen blok eronder is wat de functie doet; de insprong ken je van if en for. Achter return staat de waarde die de functie teruggeeft: wat eruit komt.

In de wiskunde heten functies meestal f en g. In een programma kies je een naam die je over een maand nog begrijpt: dubbel, kwadraat, naar_fahrenheit. Zo hou je ze uit elkaar.

Een functie aanroepen

Je gebruikt een functie door haar naam te schrijven met een waarde tussen de haakjes. Die waarde heet het argument.

print(dubbel(4))

Uitvoer:

8

Python geeft het argument 4 aan de parameter x, voert het blok uit en komt terug met 8. De aanroep dubbel(4) heeft dus de waarde 8, net zoals 2 + 3 de waarde 5 heeft. Je kan er alles mee doen wat je met een getal doet: opslaan, afdrukken of ermee verder rekenen.

resultaat = dubbel(10)
print(resultaat)
print(dubbel(3) + 1)
print(dubbel(resultaat))

Uitvoer:

20
7
40

Het argument mag ook een variabele zijn, zoals in de laatste regel. Python zoekt eerst de waarde van het argument op en geeft die dan door.

Een blok van meerdere regels

def naar_fahrenheit(celsius):
    fahrenheit = celsius * 9 / 5 + 32
    return fahrenheit

print(naar_fahrenheit(20))

Uitvoer:

68.0

Het blok mag zoveel regels tellen als nodig. De functie rekent, en de laatste regel geeft het resultaat terug. Afdrukken gebeurt buiten de functie, op de plaats waar je de waarde wil zien.

Definiëren is nog niet uitvoeren

Bij def onthoudt Python de functie, maar het blok wordt nog niet uitgevoerd. Dat gebeurt pas bij een aanroep, en bij elke aanroep opnieuw.

def kwadraat(getal):
    return getal * getal

print("start")
kwadraat(5)
print(kwadraat(3))
print(kwadraat(4))

Uitvoer:

start
9
16

De regel kwadraat(5) rekent wel 25 uit, maar niemand doet iets met die waarde: ze wordt niet opgeslagen en niet afgedrukt, dus je ziet niets. Een script dat een functie alleen definieert en nooit aanroept, toont helemaal niets.

De definitie moet boven de eerste aanroep staan. Staat print(kwadraat(3)) vóór de def, dan kent Python die naam nog niet en krijg je een NameError.

Daarmee kan je een berekening een naam geven en ze aanroepen waar je ze nodig hebt.

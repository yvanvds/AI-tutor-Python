Een voorschrift uit de wiskunde, een formule uit de fysica, een kostenfunctie uit de economie: je schrijft ze rechtstreeks als Python-functie. Daarna laat je de computer de functie voor veel waarden uitrekenen en zoek je in die waarden naar wat je wil weten.

Van formule naar functie

Het voorschrift f(x) = x² - 4x + 3 wordt:

def f(x):
    return x ** 2 - 4 * x + 3

print(f(0))
print(f(2))

Uitvoer:

3
-1

Wiskundenotatie is geen Python. Schrijf 4 * x en niet 4x, x ** 2 en niet x^2, en def f(x): met return in plaats van f(x) = ....

Een formule met meerdere grootheden krijgt meerdere parameters. Een kapitaal dat een aantal jaren uitstaat, groeit aan tot het kapitaal maal (1 + rentevoet) tot de macht van het aantal jaren:

def eindkapitaal(kapitaal, rentevoet, jaren):
    return kapitaal * (1 + rentevoet) ** jaren

print(round(eindkapitaal(1000, 0.02, 10), 2))

Uitvoer:

1218.99

Met round(waarde, 2) rond je af op twee cijfers na de komma.

De math-module

Wortels, het getal pi en goniometrische functies zitten in de module math. Je importeert ze zoals turtle en zet de modulenaam voor wat je gebruikt.

import math

def schuine_zijde(a, b):
    return math.sqrt(a ** 2 + b ** 2)

def omtrek_cirkel(straal):
    return 2 * math.pi * straal

print(schuine_zijde(3, 4))
print(round(omtrek_cirkel(10), 2))

Uitvoer:

5.0
62.83

math.sin en math.cos rekenen in radialen, niet in graden.

Een waardetabel

for x in range(0, 5):
    print(x, f(x))

Uitvoer:

0 3
1 0
2 -1
3 0
4 3

range(0, 5) levert 0 tot en met 4: de tabel heeft vijf rijen en de 5 zelf hoort er niet bij. Wil je de waarden later nog gebruiken, dan bewaar je ze in een lijst met append in plaats van ze af te drukken.

range kent alleen gehele getallen. Voor een fijnere tabel laat je de lus de rijen tellen en reken je x zelf uit: de beginwaarde plus het rijnummer maal de stap.

start = 0
stap = 0.5
for i in range(5):
    x = start + i * stap
    print(x, f(x))

Uitvoer:

0.0 3.0
0.5 1.25
1.0 0.0
1.5 -0.75
2.0 -1.0

Hier loopt i van 0 tot en met 4, dus x van 0 tot en met 2. Vier stappen van 0.5 geven vijf rijen: altijd één rij meer dan er stappen zijn.

Zoeken in functiewaarden

Waar is f het kleinst? Dat is het patroon van het kleinste element zoeken, nu toegepast op functiewaarden:

kleinste_x = 0
for i in range(17):
    x = i * 0.25
    if f(x) < f(kleinste_x):
        kleinste_x = x
print(kleinste_x, f(kleinste_x))

Uitvoer:

2.0 -1.0

Een nulpunt vind je tussen twee x-waarden waar de functie van teken wisselt: de ene functiewaarde is positief, de andere negatief. Hun product is dan negatief.

def g(x):
    return x ** 3 - x - 1

for i in range(8):
    links = i * 0.25
    rechts = links + 0.25
    if g(links) * g(rechts) < 0:
        print("tekenwissel tussen", links, "en", rechts)

Uitvoer:

tekenwissel tussen 1.25 en 1.5

De stap bepaalt wat je ziet

def h(x):
    return (x - 1.25) * (x - 1.75)

print(h(1), h(2))
print(h(1.5))

Uitvoer:

0.1875 0.1875
-0.0625

Een tabel toont alleen de punten die je uitrekent. Met stap 1 is h in beide buurpunten positief: geen tekenwissel, dus geen nulpunt gevonden. Toch duikt de functie tussen 1 en 2 onder nul; ze heeft daar twee nulpunten en haar minimum. Een te grote stap stapt er gewoon overheen.

Een kleinere stap vindt meer, maar vraagt meer rekenwerk, en zekerheid dat je niets mist geeft een tabel nooit.

Zo onderzoek je met de computer een functie waarvan je alleen het voorschrift kent.

From math you know functions such as f(x) = 2x: you put a number in and a number comes out. In Python you write such functions yourself, with a name that says what they do.

From f(x) to def

def double(x):
    return 2 * x

The first line starts with def. Then comes the name of the function, the parameter in parentheses, and a colon. The parameter x is the name for the value that comes in.

The indented block below it is what the function does; you know the indentation from if and for. After return comes the value the function gives back: what comes out.

In math, functions are usually called f and g. In a program you choose a name you will still understand a month from now: double, square, to_fahrenheit. That is how you keep them apart.

Calling a function

You use a function by writing its name with a value in the parentheses. That value is called the argument.

print(double(4))

Output:

8

Python gives the argument 4 to the parameter x, runs the block and comes back with 8. So the call double(4) has the value 8, just as 2 + 3 has the value 5. You can do anything with it that you do with a number: store it, print it or calculate further with it.

result = double(10)
print(result)
print(double(3) + 1)
print(double(result))

Output:

20
7
40

The argument can also be a variable, as in the last line. Python first looks up the value of the argument and then passes it on.

A block of several lines

def to_fahrenheit(celsius):
    fahrenheit = celsius * 9 / 5 + 32
    return fahrenheit

print(to_fahrenheit(20))

Output:

68.0

The block can have as many lines as it needs. The function calculates, and the last line gives back the result. Printing happens outside the function, at the place where you want to see the value.

Defining is not yet running

At def, Python remembers the function, but the block is not run yet. That only happens at a call, and again at every call.

def square(number):
    return number * number

print("start")
square(5)
print(square(3))
print(square(4))

Output:

start
9
16

The line square(5) does calculate 25, but nobody does anything with that value: it is not stored and not printed, so you see nothing. A script that only defines a function and never calls it shows nothing at all.

The definition has to be above the first call. If print(square(3)) comes before the def, Python doesn't know that name yet and you get a NameError.

With that you can give a calculation a name and call it wherever you need it.

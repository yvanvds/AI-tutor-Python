Met input() vraag je iets aan de gebruiker. Het script stopt even, wacht tot de gebruiker iets typt en op enter drukt, en geeft daarna terug wat er getypt is. Die waarde sla je meestal op in een variabele om er verder mee te werken.

Een vraag stellen

Tussen de haakjes van input() zet je een tekst — de prompt. Die verschijnt op het scherm zodat de gebruiker weet wat je wil weten. Vergeet niet een spatie aan het einde van de prompt te zetten, anders kleeft de invoer tegen je vraag.

naam = input("Hoe heet je? ")
print("Hallo", naam)

Wat de gebruiker typt — bijvoorbeeld Mira — komt in naam terecht. Daarna toont print de begroeting.

Input geeft altijd een string

Dit is de belangrijkste regel van deze les: input() geeft altijd een string terug, ook als de gebruiker een getal typt. Voor Python is "42" dat de gebruiker intypte gewoon tekst die toevallig uit cijfers bestaat — geen getal.

leeftijd = input("Hoe oud ben je? ")
print(leeftijd + 1)

Bovenstaand script crasht. De gebruiker typt 16, maar leeftijd bevat de string "16". En "16" + 1 kan Python niet uitvoeren — een string en een getal kan je niet optellen, dus krijg je een TypeError.

Een nog subtielere variant: vraag twee getallen op zonder ze om te zetten en tel ze op.

a = input("Eerste getal? ")
b = input("Tweede getal? ")
print(a + b)

Typt de gebruiker 5 en 3, dan verschijnt 53 op het scherm, niet 8. Tussen twee strings betekent + namelijk plakken, niet optellen. Het script geeft geen foutmelding, alleen een fout antwoord — dat soort bug is moeilijker te vinden.

Omzetten naar een getal

Wil je met de invoer rekenen, dan zet je de string eerst om naar een getal. Daarvoor heb je twee functies: int() voor hele getallen en float() voor kommagetallen.

leeftijd = int(input("Hoe oud ben je? "))
print("Volgend jaar word je", leeftijd + 1)

De binnenste aanroep input(...) vraagt de tekst op, en int(...) zet die tekst onmiddellijk om naar een geheel getal. In leeftijd zit dus meteen een int.

Voor kommagetallen werkt het hetzelfde:

gewicht = float(input("Wat is je gewicht in kg? "))
print("In gram:", gewicht * 1000)

Wanneer de omzetting faalt

Niet elke tekst kan omgezet worden naar een getal. Wat de gebruiker typt moet er ook echt uitzien als een geldig getal, anders krijg je een ValueError en stopt het script.

int("16") werkt. int("zestien") niet, want dat is geen getal. Ook int("3.5") werkt niet — int verwacht een heel getal zonder komma of punt. Voor 3.5 heb je float nodig.

In België schrijf je 3,14 met een komma, maar float verwacht een punt. Typt de gebruiker 3,14 aan een float(input(...))-vraag, dan crasht het script met een ValueError. Wil je dat het script werkt, dan moet de gebruiker een punt typen.

Bisection traps a zero. There is a second way of searching: start with an estimate and improve it, again and again, until it no longer changes.

The square root according to Heron

x = 2
x = (x + 16 / x) / 2
print(x)
x = (x + 16 / x) / 2
print(x)

Output:

5.0
4.1

You are looking for the square root of 16 and guess 2. If the estimate is too small, 16 divided by the estimate is too large: 16 / 2 = 8. The real root lies in between, so you take the average of the two: 5. Then the same with 5: the average of 5 and 3.2 is 4.1. Every step is closer to 4.

Improving until it is stable

def square_root(a, tolerance):
    old = a
    new = (old + a / old) / 2
    while abs(new - old) > tolerance:
        old = new
        new = (old + a / old) / 2
    return new

print(square_root(2, 0.000001))

Output:

1.414213562373095

There is no interval here that gets narrower. You stop when two successive estimates differ by less than the tolerance. That is why the loop keeps two variables: the previous estimate and the new one. If you compare an estimate with itself, the loop stops at once.

The slope of a function

def slope(f, x):
    h = 0.0001
    return (f(x + h) - f(x)) / h

def f(x):
    return x ** 3 - x - 1

print(round(slope(f, 2), 2))

Output:

11.0

You approximate the slope at a point by taking a very small step h sideways and looking at how much the function rises: the difference in function value divided by h. You don't need derivative rules for it, only the function itself.

A Newton step

x = 2
x = x - f(x) / slope(f, x)
print(round(x, 3))

Output:

1.545

Newton follows the tangent line. At the estimate x = 2 the function value is 5 and the slope is 11. If you walk down along that straight line, you reach the axis 5 / 11 further to the left. That point is the next estimate: x - f(x) / slope.

def newton(f, start, tolerance):
    old = start
    new = old - f(old) / slope(f, old)
    steps = 1
    while abs(new - old) > tolerance:
        old = new
        new = old - f(old) / slope(f, old)
        steps += 1
    return new, steps

solution, steps = newton(f, 2, 0.000001)
print(round(solution, 4), steps)

Output:

1.3247 6

The loop is Heron's, with a different rule for improving. It also counts its steps and gives them back together with the solution.

Fast, but not without risk

From 1 to 2, bisection needs twenty steps to get to within a millionth: every step gains a factor of 2. Newton and Heron roughly double the number of correct digits per step and are there after a handful of steps.

Newton can fail. Where the graph runs flat, the slope is almost zero: the division then gives a huge jump and the next estimate lands far away, sometimes at another zero. That can't happen to bisection once it has a sign change.

Choose bisection when you want certainty and know a sign change. Choose Newton when you have a good start value and speed matters.

An estimate, a rule for improving it and a stop condition: a search method needs nothing more.

For x² = 9 you have a formula, for x³ = x + 1 you don't. Yet that equation has a solution, and a computer finds it by searching. Searching doesn't produce an exact answer but an approximation, and that starts with how a computer calculates with decimal numbers.

Decimal numbers are almost right

print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(0.5 + 0.25 == 0.75)

Output:

0.30000000000000004
False
True

The computer stores most decimal numbers rounded by a tiny amount. For 0.1 and 0.2 that gives a sum that is just next to 0.3. Halves and quarters it can store exactly, which is why the third line is right. So don't compare decimal numbers with ==.

Close enough is equal

def almost_equal(a, b, tolerance):
    return abs(a - b) < tolerance

print(almost_equal(0.1 + 0.2, 0.3, 0.000001))

Output:

True

You ask whether the difference is smaller than a tolerance: a small number that says how much deviation you accept.

Don't forget abs. Without it a - b is negative as soon as a is smaller than b, and then the condition is always true, however far apart the two numbers are.

From equation to zero

Bring everything to one side: x³ = x + 1 becomes x³ - x - 1 = 0. The solution of the equation is then the zero of the function f(x) = x³ - x - 1, the x for which the function becomes zero.

def f(x):
    return x ** 3 - x - 1

print(f(1))
print(f(2))

Output:

-1
5

You can rewrite every equation this way. "Where are costs and revenue equal?" also becomes "where is revenue minus costs zero?".

Looking where the zero is

import matplotlib.pyplot as plt

xs = []
ys = []
for i in range(101):
    x = i * 0.02
    xs.append(x)
    ys.append(f(x))
plt.plot(xs, ys)
plt.grid()
plt.xlabel("x")
plt.ylabel("f(x)")
plt.show()

The zero is the place where the graph crosses the horizontal axis. The grid shows that this happens between 1 and 1.5. The graph gives the neighborhood, not the answer: that is what the search methods that follow are for.

Is this a solution?

x = 1.3247
print(round(f(x), 4))
print(abs(f(x)) < 0.001)

Output:

-0.0001
True

You test an approximation by filling it in. The function value is not exactly zero, but it is closer to zero than the tolerance: x = 1.3247 is accepted as a solution. The test is abs(f(x)) < tolerance, never f(x) == 0.

Why an approximation is enough

You know a price to the cent, a measured temperature to a tenth of a degree. An answer that is right to a millionth is then just as useful as an exact answer. You choose yourself how small the error may be, and for most equations there simply is no formula.

With a function, a tolerance and a graph you are ready to search for solutions.

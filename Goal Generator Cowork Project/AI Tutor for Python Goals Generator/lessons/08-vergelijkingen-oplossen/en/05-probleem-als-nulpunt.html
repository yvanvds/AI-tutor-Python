A cup of coffee at 90 degrees stands in a room at 20 degrees. Every minute a tenth of the temperature difference with the room disappears. After how many minutes is the coffee 40 degrees? For such a question you don't need a formula, only a plan.

First a plan

QuestionFor the coffee
What is the unknown?The time t, in minutes
Which function has to become zero?The temperature at time t, minus 40
Between which values do you search?Two moments between which that function changes sign
How do you check the answer?Fill the time you found into the model: does 40 come out?

The model and the function

def temperature(t):
    return 20 + 70 * 0.9 ** t

def f(t):
    return temperature(t) - 40

print(temperature(0))
print(round(f(0), 1), round(f(30), 1))

Output:

90.0
50.0 -17.0

The difference with the room starts at 70 degrees and is multiplied by 0.9 every minute. The function f is zero at the moment the temperature is 40: positive as long as the coffee is warmer, negative after that.

Finding a start interval

def find_interval(f, start, step, count):
    for i in range(count):
        left = start + i * step
        right = left + step
        if f(left) * f(right) < 0:
            return left, right
    return None

print(find_interval(f, 0, 5, 10))

Output:

(10, 15)

This is the sign change in a table of values, now as a function: it steps through time in steps of 5 minutes and gives back the first two neighbors between which f changes sign. If it finds nothing, it gives back None.

Solving and checking

def bisection(f, a, b, tolerance):
    while b - a > tolerance:
        m = (a + b) / 2
        if f(a) * f(m) < 0:
            b = m
        else:
            a = m
    return (a + b) / 2

left, right = find_interval(f, 0, 5, 10)
t = bisection(f, left, right, 0.0001)
print(round(t, 2))
print(round(temperature(t), 2))

Output:

11.89
40.0

After almost 12 minutes the coffee is 40 degrees. The check happens in the original problem, not in the solver: you fill the time you found into the model and see whether 40 comes out. Also ask yourself whether the answer can be right. A negative time or three days of waiting would reveal an error here.

The solution on the graph

import matplotlib.pyplot as plt

times = []
values = []
for i in range(61):
    times.append(i * 0.5)
    values.append(f(i * 0.5))
plt.plot(times, values)
plt.scatter([t], [0], color="red")
plt.grid()
plt.xlabel("time (minutes)")
plt.ylabel("temperature minus 40 (degrees)")
plt.show()

The red point is on the axis, at the time you found. If it lies exactly where the line crosses the axis, the solution is right; a point next to it shows at once that something is wrong. The figure above shows the same moment on the temperature itself: the curve reaches the line of 40 degrees at t = 11.89.

Which zero do you find?

def p(x):
    return x ** 2 - 4 * x + 3

print(round(bisection(p, 0.5, 2, 0.0001), 2))
print(round(bisection(p, 2, 4.5, 0.0001), 2))

Output:

1.0
3.0

A function can have several zeros. The start interval or the start value decides which one you find, and the problem decides which one you need: the positive time, the price that fits the market.

An unknown, a function that has to become zero, an interval and a check: that is how you solve equations for which no formula exists.

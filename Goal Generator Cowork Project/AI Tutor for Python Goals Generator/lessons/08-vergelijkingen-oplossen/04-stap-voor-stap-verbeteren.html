Bisectie sluit een nulpunt in. Er is een tweede manier van zoeken: begin met een schatting en verbeter ze, telkens opnieuw, tot ze niet meer verandert.

De wortel volgens Heron

x = 2
x = (x + 16 / x) / 2
print(x)
x = (x + 16 / x) / 2
print(x)

Uitvoer:

5.0
4.1

Je zoekt de wortel van 16 en gokt 2. Is de schatting te klein, dan is 16 gedeeld door de schatting te groot: 16 / 2 = 8. De echte wortel ligt daartussen, dus neem je het gemiddelde van de twee: 5. Daarna hetzelfde met 5: het gemiddelde van 5 en 3.2 is 4.1. Elke stap ligt dichter bij 4.

Verbeteren tot het stabiel is

def wortel(a, tolerantie):
    oud = a
    nieuw = (oud + a / oud) / 2
    while abs(nieuw - oud) > tolerantie:
        oud = nieuw
        nieuw = (oud + a / oud) / 2
    return nieuw

print(wortel(2, 0.000001))

Uitvoer:

1.414213562373095

Hier is geen interval dat smaller wordt. Je stopt wanneer twee opeenvolgende schattingen minder dan de tolerantie verschillen. Daarom houdt de lus twee variabelen bij: de vorige schatting en de nieuwe. Vergelijk je een schatting met zichzelf, dan stopt de lus meteen.

De helling van een functie

def helling(f, x):
    h = 0.0001
    return (f(x + h) - f(x)) / h

def f(x):
    return x ** 3 - x - 1

print(round(helling(f, 2), 2))

Uitvoer:

11.0

De helling in een punt benader je door een heel klein stapje h opzij te zetten en te kijken hoeveel de functie stijgt: het verschil in functiewaarde gedeeld door h. Je hebt er geen afleidingsregels voor nodig, alleen de functie zelf.

Een Newton-stap

x = 2
x = x - f(x) / helling(f, x)
print(round(x, 3))

Uitvoer:

1.545

Newton volgt de raaklijn. In de schatting x = 2 is de functiewaarde 5 en de helling 11. Wie langs die rechte naar beneden loopt, komt 5 / 11 verder naar links op de as uit. Dat punt is de volgende schatting: x - f(x) / helling.

def newton(f, start, tolerantie):
    oud = start
    nieuw = oud - f(oud) / helling(f, oud)
    stappen = 1
    while abs(nieuw - oud) > tolerantie:
        oud = nieuw
        nieuw = oud - f(oud) / helling(f, oud)
        stappen += 1
    return nieuw, stappen

oplossing, stappen = newton(f, 2, 0.000001)
print(round(oplossing, 4), stappen)

Uitvoer:

1.3247 6

De lus is die van Heron, met een andere regel om te verbeteren. Ze telt ook haar stappen en geeft die samen met de oplossing terug.

Snel, maar niet zonder risico

Bisectie heeft van 1 tot 2 twintig stappen nodig om tot op een miljoenste te komen: elke stap wint een factor 2. Newton en Heron verdubbelen ruwweg het aantal juiste cijfers per stap en zijn er na een handvol stappen.

Newton kan mislukken. Waar de grafiek vlak loopt, is de helling bijna nul: de deling geeft dan een reusachtige sprong en de volgende schatting belandt ver weg, soms bij een ander nulpunt. Bisectie kan dat niet overkomen zodra ze een tekenwissel heeft.

Kies bisectie als je zekerheid wil en een tekenwissel kent. Kies Newton als je een goede startwaarde hebt en snelheid telt.

Een schatting, een regel om ze te verbeteren en een stopvoorwaarde: meer heeft een zoekmethode niet nodig.
